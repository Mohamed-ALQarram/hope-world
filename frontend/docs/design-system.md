# Hope World — Design System

## Brand Colors

Navy   #24334A
Pink   #FF5E7E
Yellow #FFD13B
Blue   #38B6FF

Use these as the core brand palette.

## Visual Direction

The UI must feel:
- Child-friendly
- Gamified
- Playful
- Modern
- Premium
- Educational

It must NOT feel like:
- A traditional LMS
- A corporate dashboard
- A generic login page

## UI Principles

- Large touch targets
- Clear hierarchy
- Minimal cognitive load
- Rounded components
- Soft shadows
- Playful illustrations
- Friendly characters
- Positive feedback
- Strong progress visualization

## Gamification

Use where appropriate:
- Stars
- Badges
- Rewards
- Unlock states
- Progress paths
- Celebrations
- Avatars

Avoid unnecessary complexity or competitive mechanics.

## Navigation

The product is organized around a gamified world.

Typical flow:

World
→ Island
→ Subject
→ Level
→ Learning Model
→ Quiz

## Arabic / English

Arabic:
- RTL

English:
- LTR

Do not solve RTL by changing text alignment only.
Check layout direction and directional UI elements as well.

## Reusability

Prefer reusable:
- Buttons
- Cards
- Progress indicators
- Avatar components
- Audio controls
- Video containers
- Quiz components
